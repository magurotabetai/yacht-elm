# Yacht Elm - ダイスバトルRPG

ヨット（Yacht）というダイスゲームをベースにしたRPG風バトルゲームです。様々なキャラクターを使い、ダイスの目を駆使して敵と戦います。

## ゲーム概要

「ヨット・エルム」は、伝統的なダイスゲーム「ヨット」をベースにした戦略的RPGです。プレイヤーは個性豊かなキャラクターを選び、ダンジョンを進みながら様々な敵と戦います。バトルではダイスを振り、出た目を最適な形で組み合わせてスコアを獲得し、敵にダメージを与えます。

### 主な特徴

- **多彩なキャラクター**: それぞれ固有の特殊能力を持つキャラクターから選択可能
- **戦略的バトル**: ダイスの目を組み合わせて最適なスコアを狙うターン制バトル
- **ローグライク要素**: ランダム生成されるマップと敵、戦略的な経路選択
- **アイテムシステム**: バトルを有利に進めるための様々なアイテム

## キャラクター

- **ラッキーローラー**: 元ギャンブラーで運に恵まれた冒険者。**3回のリロールチャンス**を持ち、幸運な一投で勝負を決める。
- **ストラテジスト**: 戦略家。特定のスコア組み合わせでボーナスダメージを得る。

## セットアップ

依存関係をインストール:

```bash
bun install
```

## 開発方法

開発サーバーを起動:

```bash
bun dev
```

## ビルド方法

プロダクション用にアプリをビルド:

```bash
bun run build
```

ビルドしたアプリをローカルでプレビュー:

```bash
bun run preview
```

## ゲームプレイ方法

1. スタート画面からキャラクターを選択
2. マップ上で進む道を選び、様々なイベントに挑戦
3. バトルでは5つのダイスを振り、最適なスコアを狙う
4. リロールを使って望ましくない目を振り直す（ラッキーローラーは3回、他は2回）
5. 敵のHPを0にすると勝利

## ヨットのスコアルール

- **エース～シックス**: 対応する数字のダイスの合計
- **チョイス**: 全てのダイスの合計
- **フォーカインド**: 4つ以上同じ目が出たら全ダイスの合計
- **フルハウス**: 3つの同じ目と2つの同じ目で全ダイスの合計
- **スモールストレート**: 4つの連続した数字で15点
- **ラージストレート**: 5つの連続した数字で30点
- **ヨット**: 全て同じ目で50点
